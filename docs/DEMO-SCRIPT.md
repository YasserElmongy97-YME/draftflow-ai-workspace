# Demo Walkthrough Script (60-90 seconds)

1. **Workspace Overview (0:00 - 0:15)**: Open the app directly into the dark editorial workspace. Point out the collapsible sidebar, draft brief controls, and clean writing canvas.
2. **Template & Generation (0:15 - 0:35)**: Select **Technical Deep Dive**, set tone to **Technical** and length to **Medium**, enter a topic, and click **Generate draft**. Show streaming output and live monospace telemetry (words, reading time, headings).
3. **Inline Revision & Editing (0:35 - 0:50)**: Edit a line directly, toggle **Preview**, then click **Tighten** or **Shift tone** in the Revise bar to create a tracked `v2` snapshot.
4. **Immutable Version History & Restore (0:50 - 1:05)**: Open **Versions**, inspect `v1` vs `v2`, and restore `v1` to show it creates `v3` without losing history.
5. **Export & Import Round-Trip (1:05 - 1:25)**: Open **Export** to download `.md` (with YAML frontmatter), then open **Import** and re-upload that `.md` file to demonstrate seamless round-trip editing and metadata detection. Briefly show **History** and **Templates**.
